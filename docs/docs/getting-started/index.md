# Getting Started

Welcome to Bioctree! This guide will help you get up and running with spatiotemporal-spectral signal processing on cortical manifolds.

## What is Bioctree?

Bioctree is a MATLAB toolbox that combines differential geometry, graph signal processing, and time-frequency analysis to enable powerful analysis of neural signals on brain surface meshes.

**Key capabilities:**
- Spectral decomposition using Laplace-Beltrami operators
- Spatial filtering in eigenspace
- Traveling wave detection and characterization  
- Joint spatiotemporal-spectral analysis
- HDF5-based data management

## System Requirements

### Minimum Requirements
- **MATLAB**: R2020a or later
- **Operating System**: Windows, macOS, or Linux
- **RAM**: 8 GB minimum
- **Storage**: 500 MB for toolbox + data

### Recommended
- **MATLAB**: R2023a or later
- **RAM**: 16 GB or more (for large meshes)
- **GPU**: Optional, for accelerated computations
