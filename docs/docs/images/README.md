# Hero Background Image

## Required Image: `hero-bg.png`

For the best visual experience on the homepage, please add a background image named `hero-bg.png` in this directory.

### Recommended Specifications

- **Dimensions**: 1920x1080 or larger
- **Format**: PNG with transparency support
- **Theme**: Abstract scientific/neural visualization (brain networks, wave patterns, cortical mesh, etc.)
- **Color Palette**: Should work with the blue/cyan gradient overlay (consider using lighter backgrounds)

### Alternative Options

If you don't have a custom image ready:

1. **Use a solid gradient** - The CSS already provides beautiful gradients, so the image is optional
2. **Download from Unsplash** - Search for "brain network", "neural waves", or "cortical mesh"
3. **Generate using visualization tools** - Export a cortical mesh rendering from your MATLAB visualizations

### Current State

The hero section will display with just the gradient overlay until you add the image. The site is fully functional without it!
