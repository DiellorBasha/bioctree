# Concepts

Welcome to the Concepts section of Bioctree documentation. Here you'll find detailed explanations of the fundamental concepts underlying spatiotemporal-spectral signal processing on cortical manifolds.

## Overview

Bioctree combines concepts from differential geometry, graph signal processing, and time-frequency analysis to enable powerful analysis of neural signals on brain surface meshes.
