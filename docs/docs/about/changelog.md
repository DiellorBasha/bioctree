# Changelog

All notable changes to Bioctree will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Complete MkDocs documentation website
- Comprehensive API reference
- Tutorial system
- Example gallery

## [0.3.0] - 2025-01-XX

### Added
- Domain inheritance architecture
- Joint domain support (Lambda × Omega)
- Wave packet filters
- Dispersion relation computation
- BCT file format with HDF5
- Multi-layer signal support
- Schema validation system

### Changed
- Refactored filter system to use domain-based architecture
- Unified transform interface
- Improved eigendecomposition performance

### Fixed
- Mass matrix normalization issues
- Edge case handling in sparse eigensolver

## [0.2.0] - 2024-12-XX

### Added
- Graph signal processing support
- Fundamental kernel library
- Filter designer app
- Visualization subsystem (+show)

### Changed
- Migrated from functional to object-oriented architecture
- Replaced mesh-specific code with domain abstraction

## [0.1.0] - 2024-11-XX

### Added
- Initial release
- Basic mesh loading
- Eigendecomposition
- Simple filtering
- FreeSurfer mesh support

## Version History

- **0.3.0**: Domain architecture, wave packets, BCT format
- **0.2.0**: OOP refactoring, filter designer
- **0.1.0**: Initial prototype
