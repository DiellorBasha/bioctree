# Signal Generation Migration Guide

## Overview

The Signal class has been refactored to use a **Mask-based generation system** that leverages the unified Filter/Kernel framework. This provides a more flexible, powerful, and consistent approach to signal generation.

---

## What Changed

### ❌ DEPRECATED: `Signal.createDelta()`

The old `createDelta()` static method has been **removed**. It was limited to creating impulse signals only and didn't integrate with the kernel/filter system.

### ✅ NEW: Mask-Based Generation

Signals are now generated by:
1. Creating a **Filter** (mask) with any kernel
2. Evaluating the filter on the domain axis
3. Optionally normalizing the result

This works with **ALL kernels**, not just delta.

---

## Migration Examples

### Example 1: Delta Impulse on Time Domain

**OLD CODE (deprecated):**
```matlab
% Create delta at time index 500
sig = bct.Signal.createDelta(B.Time, 500);
```

**NEW CODE:**
```matlab
% Create delta filter at time value (not index)
mask = bct.filters.Filter(B.Time, 'delta', 'x0', B.Time.axis(500));

% Generate signal with unit energy normalization
sig = bct.Signal.fromMask(mask, 'normalize', 'energy');
```

**Key Differences:**
- Use **time value** (from `B.Time.axis`) instead of index
- Explicit normalization control
- Mask reference stored in `sig.Mask` for later updates

---

### Example 2: Delta Impulse on Lambda Domain

**OLD CODE:**
```matlab
sig = bct.Signal.createDelta(B.Lambda, 50);
```

**NEW CODE:**
```matlab
mask = bct.filters.Filter(B.Lambda, 'delta', 'x0', B.Lambda.axis(50));

```

---

### Example 3: Delta on Joint Domain (Spatiotemporal)

**OLD CODE:**
```matlab
% Delta at vertex 100, time index 25
sig = bct.Signal.createDelta(B.Joint, 100, 25);
```

**NEW CODE:**
```matlab
% For joint domains, use Gabor as localized impulse approximation
joint = B.createJoint('Manifold', 'Time');

mask = bct.filters.Filter(joint, 'gabor', ...
    'center_x', B.Manifold.axis(100), ...
    'center_y', B.Time.axis(25), ...
    'sigma_x', 1, ...   % Narrow spatial width
    'sigma_y', 0.001);  % Narrow temporal width

sig = bct.Signal.fromMask(mask, 'normalize', 'energy');
```

**Note:** True delta on joint domains requires 2D delta kernel (future enhancement). For now, use very narrow Gabor as approximation.

## Normalization Modes

The new system supports **three normalization modes**:

### 1. No Normalization (`'none'`)
```matlab
sig = bct.Signal.fromMask(mask, 'normalize', 'none');
```
Raw kernel values, no scaling.

### 2. Unit Energy (`'energy'`)
```matlab
sig = bct.Signal.fromMask(mask, 'normalize', 'energy');
```
Normalized so that `||signal|| = 1` (L2 norm).

**Use case:** Energy-preserving transforms, spectral analysis.

### 3. Unit Peak (`'peak'`)
```matlab
sig = bct.Signal.fromMask(mask, 'normalize', 'peak');
```
Normalized so that `max(|signal|) = 1`.

**Use case:** Visualization, comparing different kernels.

## Dynamic Mask Updates

One of the **key advantages** of the new system is dynamic updates for interactive applications.

### Example: Interactive Gaussian Signal
```matlab
% Create initial signal
mask = bct.filters.Filter(B.Time, 'gaussian', 'center', 0.3, 'sigma', 0.05);
sig = bct.Signal.fromMask(mask, 'normalize', 'energy');

% Later, user moves slider → update center
mask.center = 0.7;

% Regenerate signal with updated mask
sig.setMask(mask, 'normalize', 'energy');

% Signal data automatically updated!
```

### Example: Integration with KernelEditor
```matlab
% Create editor for GUI control
editor = bct.ui.TimeWindowEditor(B.Time, mask, 0.5, 0.1);

% Generate signal from editor's filter
sig = bct.Signal.fromMask(editor.Filter, 'normalize', 'energy');

% User interaction: shift forward
editor.shiftForward(3);

% Regenerate signal
sig.setMask(editor.Filter, 'normalize', 'energy');
```

## Property: `Signal.Mask`

The new `Mask` property stores the **Filter object** that generated the signal.

### Usage
```matlab
mask = bct.filters.Filter(B.Time, 'delta', 'x0', 0.5);
sig = bct.Signal.fromMask(mask);

% Mask is stored
assert(~isempty(sig.Mask));
assert(sig.Mask == mask);

% Can query mask parameters
fprintf('Impulse location: %.2f\n', sig.Mask.Parameters.x0);

% Update mask and regenerate
sig.Mask.x0 = 0.8;
sig.Data = sig.evaluateMask('normalize', 'energy');
```

## Complete Workflow Comparison

### OLD Workflow (Limited to Delta Only)
```matlab
% Step 1: Create delta signal by index
sig = bct.Signal.createDelta(B.Time, 500);

% Step 2: ???
% (No way to update or change parameters)
```

### NEW Workflow (All Kernels, Dynamic Updates)
```matlab
% Step 1: Create Filter (mask) with any kernel
mask = bct.filters.Filter(B.Time, 'delta', 'x0', 0.5);

% Step 2: Generate signal with normalization
sig = bct.Signal.fromMask(mask, 'normalize', 'energy');

% Step 3: Update mask parameters
mask.x0 = 0.7;  // Move impulse
mask.Parameters.tol = 0.002;  // Change tolerance

% Step 4: Regenerate signal
sig.setMask(mask, 'normalize', 'energy');

% Step 5: Query mask properties
fprintf('Impulse at t=%.3f\n', mask.Parameters.x0);
```

## API Summary

### Static Methods

#### `Signal.fromMask(filter, Name, Value)`
Generate signal by evaluating filter on domain axis.

**Parameters:**
- `filter` - bct.filters.Filter object
- `'normalize'` - `'none'`, `'energy'`, or `'peak'` (default: `'none'`)
- `'label'` - Custom label (default: auto-generated)

**Returns:**
- Signal object with `Data = normalized(filter.evaluate())`

---

### Instance Methods

#### `sig.setMask(filter, Name, Value)`
Set or update mask and regenerate signal data.

**Parameters:**
- `filter` - bct.filters.Filter object (must match `sig.Domain`)
- `'normalize'` - Normalization mode (default: `'none'`)
- `'update_label'` - Update signal label (default: `false`)

**Effect:**
- Stores `filter` in `sig.Mask`
- Regenerates `sig.Data` by evaluating filter
- Optionally updates `sig.Label`

---

#### `data = sig.evaluateMask(Name, Value)`
Evaluate current mask with optional normalization.

**Parameters:**
- `'normalize'` - Normalization mode (default: `'none'`)

**Returns:**
- Evaluated and normalized kernel values

**Use case:** When mask parameters changed externally, regenerate data without creating new Signal.

## Benefits Summary

| Feature | OLD (createDelta) | NEW (Mask-based) |
|---------|-------------------|------------------|
| **Kernels supported** | Delta only | ALL kernels |
| **Normalization** | ❌ None | ✅ energy, peak, none |
| **Dynamic updates** | ❌ Not possible | ✅ Via setMask() |
| **GUI integration** | ❌ Manual | ✅ KernelEditor |
| **Mask reference** | ❌ None | ✅ Stored in .Mask |
| **Parameter query** | ❌ Not possible | ✅ Via .Mask.Parameters |
| **Index vs Value** | Index-based | Value-based (axis) |
| **Joint domains** | Index pair | Any 2D kernel |

## Common Pitfalls

### ❌ Using Index Instead of Value
```matlab
% WRONG
mask = bct.filters.Filter(B.Time, 'delta', 'x0', 500);  // Index!

% CORRECT
mask = bct.filters.Filter(B.Time, 'delta', 'x0', B.Time.axis(500));  // Value!
```

### ❌ Forgetting to Normalize
```matlab
% May have arbitrary scaling
sig = bct.Signal.fromMask(mask);

% Better: explicit normalization
sig = bct.Signal.fromMask(mask, 'normalize', 'energy');
```

### ❌ Not Using setMask for Updates
```matlab
% WRONG: Data won't update automatically
mask.center = 0.7;
% sig.Data is now stale!

// CORRECT: Use setMask
mask.center = 0.7;
sig.setMask(mask, 'normalize', 'energy');  // Data regenerated
```
